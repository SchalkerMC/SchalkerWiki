# 📚 Schalker Wiki

Официальная вики проекта Schalker - приватного Minecraft сервера.

## 📖 О проекте

Это репозиторий с MDX файлами для вики сайта [schalker.net](https://schalker.net/wiki).

## 📝 Как редактировать

1. Откройте нужную страницу в папке `pages/`
2. Нажмите кнопку "Редактировать" (карандаш)
3. Внесите изменения
4. Создайте Pull Request

## 📂 Структура

```
pages/
├── index.mdx              # Главная страница вики
├── start.mdx              # Как начать играть
├── guilds.mdx             # Гильдии
├── commands.mdx           # Команды
├── dictionary.mdx         # Словарь терминов
├── datapacks.mdx          # Дата-паки
├── invisibleframes.mdx    # Невидимые рамки
├── invisiblelight.mdx     # Невидимый свет
├── fast-concrete.mdx      # Быстрый бетон
├── brewery.mdx            # Алкоголь
├── fishing.mdx            # Рыбалка, мешочки и починка
├── voicechat.mdx          # Голосовой чат
├── account-premium.mdx    # Вход без пароля
├── privacy-policy.mdx     # Политика конфиденциальности
└── contacts.mdx           # Контакты
```

## ✍️ Формат MDX

Каждый файл начинается с frontmatter:

```mdx
---
title: Название страницы
description: Описание
category: main  # main, gameplay, account, other
---

# Заголовок

Ваш контент...
```

## 🎨 Категории

- **main** - Основное (розовый)
- **gameplay** - Игровой контент (синий)
- **account** - Аккаунт (желтый)
- **other** - Прочее (голубой)
